# Product Control System

Product Control System (PCS) — методология построения системы, в которой программный
агент наблюдает работающий продукт, оценивает его состояние, выбирает и выполняет
допустимые воздействия, проверяет результат и возвращает полученное знание в общую
модель продукта.

PCS объединяет в одном управляемом цикле эксплуатационные, поддерживающие и продуктовые
задачи: от обращения пользователя или отклонения метрики до изменения продукта и
проверки результата в продуктивной среде.

