# Глоссарий Product Control System

Термины в таблице являются каноническими и используются на английском во всех
документах PCS. Их значения задаются в контексте методологии и не обязательно исчерпывают
значения терминов в исходных дисциплинах.

| Термин | Значение в PCS |
|---|---|
| **plant** | Объект управления: программный продукт и явно включённые в границу среды, данные и зависимости |
| **controller** | Агент и механизмы планирования и проверки правил, принимающие решение о воздействии |
| **model** | Внутреннее представление plant в controller; содержит знания, необходимые для оценки состояния и выбора воздействия |
| **sensor** | Канал получения свидетельств о состоянии plant |
| **actuator** | Типизированный способ воздействия на plant и его окружение |
| **setpoint** | Иерархия желаемых состояний, целей и допустимых диапазонов |
| **process variable estimate** | Восстановленное по свидетельствам фактическое состояние plant |
| **disturbance** | Изменение plant, не являющееся результатом текущего плана воздействия |
| **policy** | Правила допустимости выбора, авторизации и исполнения действий |
| **interlock** | Технически принудительное условие, блокирующее конкретное действие |
| **safety invariant** | Условие, сохраняемое независимо от текущего setpoint |
| **supervisory level** | Внешний уровень управления, задающий setpoint, policy и пределы полномочий |
| **sampling** | Моменты, в которые controller получает показания и принимает решение |
| **loop latency** | Время от появления значимого сигнала до проверенного результата воздействия |

## Терминологический статус

### Общепринятые термины

`plant`, `controller`, `model`, `sensor`, `actuator`, `setpoint`, `disturbance`,
`interlock`, `safety invariant`, `supervisory level`, `sampling`, `loop latency`,
MAPE-K, GitOps, SRE, OODA, reconciliation, least privilege, rollback, blast radius,
human-in-the-loop и human-on-the-loop.

### Локальные термины PCS

- Product Control System;
- операторское тактирование;
- автономное тактирование;
- итог обучения;
- восемь обязанностей цикла PCS.

Локальные термины не выдаются за общепринятую отраслевую терминологию.
